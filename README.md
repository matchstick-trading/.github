## Matchstick

Matchstick builds Matchstick Replay, a browser-based debugger for recorded market data: load a session, move through its events, and inspect the exact order-book state at any point in time.

- Site and docs: https://matchstick.trading
- Public demo (synthetic sample session, no account): https://replay.matchstick.trading
- Experiments: [matchstick-labs](https://github.com/matchstick-trading/matchstick-labs)
- Open candle schema: [opencandle](https://github.com/matchstick-trading/opencandle)
