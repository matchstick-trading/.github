# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in any Matchstick Trading
project, please report it privately rather than opening a public issue.

**Contact:** [hello@matchstick.trading](mailto:hello@matchstick.trading)

Please include as much detail as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept
- The affected repository, version, or commit

We will acknowledge your report and work with you on disclosure timing.

## Scope

This policy is the org-wide default for any `matchstick-trading` repository that does
not define its own `SECURITY.md`. Individual repositories may carry their own
`SECURITY.md` with additional, repo-specific reporting details; where one exists, it
takes precedence over this default.
