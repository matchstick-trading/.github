## Matchstick

Tools for inspecting recorded market data. Replay is a debugging and inspection tool, not a backtesting or execution platform.

Working on:

- **Replay**: browser order-book replay of imported recorded data (private for now; see the site).
- **Primitives**: headless React parts for trading screens, a developer preview ([docs and demos](https://ui.matchstick.trading)).

- Site and docs: https://matchstick.trading
- Open candle schema: [opencandle](https://github.com/matchstick-trading/opencandle)
- Experiments: [matchstick-labs](https://github.com/matchstick-trading/matchstick-labs)

Questions: hello@matchstick.trading
