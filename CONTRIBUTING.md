# Contributing

Pull requests are welcome across Matchstick Trading repositories.

Contributions are reviewed by a mix of human maintainers and automated agent
reviewers. An agent-authored review comment on your PR is normal here, not a sign
that no human is involved — a maintainer remains responsible for the final
decision on any change.

This file is the org-wide default. For repo-specific contribution details
(build steps, test commands, coding conventions, and how that repo's agents are
configured), see the `AGENTS.md` file in the repository you're contributing to.

If a repository doesn't have its own `AGENTS.md` yet, open the PR anyway and a
maintainer will fill in the gap.
